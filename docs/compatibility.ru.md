# Совместимость платформ и статус функций

Функции появляются на разных платформах не одновременно. Успешный импорт, рабочее VPN-подключение и публикация в магазине — отдельные проверки.

База таблиц — **iOS 2.2.0** и **Android APK 2.2.0 (2107)**. Проверенная **11 ноября 2026 года** карточка App Store показывает **iOS 2.2.1**, выпущенную 9 ноября, с минимумом iOS 15. В её описании указаны улучшения добавления/обновления ключей и импорта некоторых полных JSON. Это не подтверждает публикацию всех более новых интеграций провайдеров.

12 ноября 2026 года сборка загружена в App Store Connect для обработки. **В App Review ещё не отправлена, доступность в App Store не объявлена.** Базовые таблицы ниже не превращаются в обещание опубликованного обновления.

| Доработка iOS 2.2.2 | Границы поддержки |

| HTTP GET / HEAD | Общая подготовка с подключением, выбранный прокси/балансировщик, изоляция ENV и исправление геоданных Hysteria2; текущий VPN не переподключается |
| DNS, split DoH и алиасы | Совместимые схемы и ограниченные цепочки с защитой от циклов; не универсальное преобразование любого DNS |

| FinalMask / фрагментация | Совместимые URI и реальные успешные HTTP-заголовки; готовый JSON имеет приоритет, маски автоматически не складываются |

[Подробности и ограничения сборки](ios-2.2.2.ru.md). Android APK **2.2.0 (2107)** и статусы macOS / Windows остаются прежними; проверка TLS не ослабляется.

## Что показывает пинг

| Метод | Как читать результат |
| --- | --- |
| TCP | Измеренное время установки соединения без деления на 3,3. Открытый порт не доказывает авторизацию VPN и доступ в интернет. |
| DoDo Ping | Оценка: результат HTTP GET через поддерживаемый профиль, делённый на 3,3. Это не исходное HTTP-время. |
| HTTP GET / HEAD | Измеренное время запроса через профиль без деления. Это не тест скорости. |
| ICMP | Время эхо-ответа; сервер может блокировать ICMP при рабочем VPN. |

Hysteria использует UDP, поэтому обычная TCP-проверка для неё не подходит: по возможности применяется HTTP через профиль. В TCP-режиме Android балансировщики и сложные/неоднозначные JSON тоже проверяются через полный профиль, а не случайный выход. Число проверок ограничено; работающий VPN не переподключается.

## Ограничения протоколов и ОС

- AmneziaWG сохранён в Android и **не поддерживается в iOS**. Он не преобразуется в обычный WireGuard; не считайте его частью новой нативной Mac-версии.
- Обычный WireGuard поддерживается в описанных URI/профильных форматах. Это не поддержка любого набора peers или расширений Amnezia.
- Полный JSON не означает запуск произвольной серверной конфигурации Xray на телефоне. Служебные входы и запуск могут адаптироваться; протокол, транспорт, ядро и категории геоданных по-прежнему важны.
- Live Activity / Dynamic Island на iPhone требуют iOS 16.1+, подходящее устройство, разрешение и включённую настройку DoDo. Поддержка iOS 15 не включает эти системные функции.
- Для сканирования QR нужно разрешение камеры. Ручной ввод и буфер остаются альтернативами, особенно для длинных шифрованных ссылок.
- Happ crypto/диплинки, Lite Mode, общий Premium API, принудительное оформление от провайдера и No Limit Mode в описанной интеграции не поддерживаются.

## Функции для провайдеров: готовность и границы

| Возможность | Статус |
| --- | --- |
| Обычная выдача ключей | Не нужны кабинет DoDo, секретный API-токен панели или модуль. Достаточно HTTPS и поддерживаемого ответа. |
| Регистрация через Google и DNS TXT точного домена | Бесплатный ранний доступ. Одобрение DoDo — отдельная проверка, не заменяется контролем DNS. |
| Кабинет на сервере провайдера | Ранний доступ. Ограниченный клиент API DoDo, без основной админки и данных чужих сервисов. |
| Публичный бренд и сторис | Ранний доступ к интеграции: одобренный сервис, действующее DNS-подтверждение точного host, `x-dodo-provider-id` в успешном ответе и совместимая новая iOS-сборка. Сам номер опубликованной версии не подтверждает все доработки. |
| Статистика по названию/поддержке | Описана для iOS и Android. Это оценка установок и использования, не онлайн и не точное число абонентов. |
| Отчёты устройств по provider ID | Не то же самое, что группировка по названию/поддержке. Интеграция iOS проверяется; в Android эта статистика **ещё не перенесена**. Полные кроссплатформенные отчёты пока обещать нельзя. |
| Подтверждение конкретного абонента | Необязательный отдельный подписанный пилот. Публичный ID и DNS TXT не доказывают оплату или действующий аккаунт пользователя. |
| Push своим абонентам | Пока не доступны для общего подключения. Публичная привязка контента не создаёт закрытую аудиторию рассылки. |
| Auto через API провайдера | В разработке. Не помещайте административный API-токен панели в ключ пользователя. |

Кнопка «Автовыбор» DoDo временно скрыта в iOS. Балансировщик внутри полного Xray JSON от неё не зависит. Различия публичного контента и авторизации абонента — в [документации кабинета](provider-console.ru.md).

## Перед запуском для пользователей

1. Уточните платформу и установленную сборку, а не только название DoDo.
2. Проверьте импорт, обновление и реальное подключение со своим профилем, DNS и транспортом.
3. Проверьте резервный адрес после того, как приложение получило его успешным ответом.
4. Оставьте ручной ввод/буфер для защищённых ссылок и совместимый путь для старых клиентов.
5. Сверьтесь с [историей выпусков и обратной связью](updates-feedback.ru.md), прежде чем считать ранний доступ общедоступной функцией.

Ошибка импорта не должна превращаться в «успешное» добавление только части списка. При неудачном обновлении старые серверы сохраняются. Это защищает данные, но не исправляет недоступный сервис, неверный пароль или сломанный маршрут на стороне провайдера.
