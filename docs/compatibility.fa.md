# سازگاری پلتفرم‌ها و وضعیت قابلیت‌ها

قابلیت‌های DoDo هم‌زمان به همهٔ پلتفرم‌ها نمی‌رسند. ورود موفق پیکربندی، اتصال واقعی VPN و انتشار در فروشگاه سه موضوع جداگانه‌اند.

مبنای جدول‌ها **iOS 2.2.0** و **Android APK 2.2.0 (2107)** است. صفحهٔ App Store در بررسی **11 نوامبر 2026** نسخهٔ **iOS 2.2.1** را نشان می‌دهد که 9 نوامبر منتشر شده و به iOS 15 یا جدیدتر نیاز دارد. یادداشت آن به بهبود افزودن/به‌روزرسانی کلید و ورود برخی JSONهای کامل اشاره می‌کند؛ این به‌معنای انتشار همهٔ یکپارچه‌سازی‌های جدید ارائه‌دهندگان نیست.

## پلتفرم‌ها

| پلتفرم | انتشار و محدودهٔ مستندات |
| --- | --- |
| iPhone / iPad | نسخهٔ App Store، برای iOS 15+. بعضی امکانات سیستم به نسخهٔ جدیدتر یا سخت‌افزار سازگار نیاز دارند. نسخهٔ جاری را در فروشگاه ببینید. |
| Android | APK مستندشده نسخهٔ 2.2.0 (2107) است. انتشار در Google Play مرحله‌ای جداست. اگر برنامه را از Google Play نصب کرده‌اید، از همان فروشگاه به‌روزرسانی کنید؛ امضاها ممکن است متفاوت باشند. برای نصب APK، کلیدها و داده‌ها را حذف نکنید. |
| macOS | نسخهٔ منتشرشدهٔ Mac و نسخهٔ جدید بومی امکانات یکسانی ندارند. طراحی بومی و به‌روزرسانی هسته جداگانه آماده می‌شوند؛ امکانات منتشرنشده را موجود در Mac App Store فرض نکنید. |
| Windows | در دست آماده‌سازی است؛ هنوز نسخهٔ عمومی برای تضمین برابری امکانات وجود ندارد. |

لینک‌های دانلود و خبر انتشار در [وب‌سایت](https://dodoproxy.app/) قرار دارند. در گزارش مشکل، نسخهٔ نصب‌شده را بنویسید.

## ورود پیکربندی، مسیریابی و استفادهٔ روزمره

«محدود» یعنی پشتیبانی در چارچوب قالب‌ها و محدودیت‌های مستند، نه هر پیکربندی ممکن.

| قابلیت | iOS مبنا | Android APK مبنا | macOS | Windows |
| --- | --- | --- | --- | --- |
| URI / Base64 / JSON کامل Xray | موجود، با اعتبارسنجی پروفایل | موجود؛ پروفایل وابسته کامل حفظ می‌شود | نسخهٔ نصب‌شده و پروفایل را بررسی کنید | در آماده‌سازی |
| مسیریابی و balancer در JSON کامل | برای پروفایل‌های پشتیبانی‌شده؛ بدون شکستن به خروجی‌های مستقل | برای پروتکل اصلی و وابستگی‌های شناخته‌شده | پیاده‌سازی بومی انتشار جداگانه دارد | در آماده‌سازی |
| DoDo crypt1 / AGE1 برای DoDo | موجود | کلیپ‌بورد و ورود دستی؛ QR متراکم crypt1 در بعضی HUAWEIها قابل‌اعتماد نیست | انتشار انتقال به Mac جدید تأیید نشده است | برنامه‌ریزی‌شده |
| `fallback-url` | پس از دریافت نشانی پشتیبان از پاسخ موفق | موجود؛ نشانی باید از قبل دریافت شده باشد | در نسخهٔ منتشرشدهٔ مبنا موجود نیست | در آماده‌سازی |
| فراداده و `profile-update-interval` | موجود | موجود | نسخهٔ نصب‌شده را ببینید | در آماده‌سازی |
| Routing / autorouting / داده‌های داخلی | موجود با محدودیت قالب و بازبینی | موجود؛ بازه‌های بازبینی متفاوت‌اند | برابری با موبایل را فرض نکنید | در آماده‌سازی |
| TCP، DoDo Ping، HTTP GET، HTTP HEAD، ICMP | موجود | موجود با روش متناسب با پروفایل | نسخهٔ نصب‌شده را ببینید | در آماده‌سازی |
| MTU و ترجیح IPv4 / IPv6 | موجود | موجود | نسخهٔ نصب‌شده را ببینید | در آماده‌سازی |
| لاگ زنده، اشتراک QR و بازنشانی با تأیید | موجود | موجود؛ محدودیت دوربین crypt1 بالا اعمال می‌شود | نسخه و رابط نصب‌شده را ببینید | در آماده‌سازی |
| گزارش فنی با رضایت کاربر | موجود، با پوشش محدود | موجود، با پوشش محدود | ارسال در موبایل به‌معنای وجود آن در Mac نیست | در آماده‌سازی |

پیش از فعال‌کردن برای همهٔ مشتریان، [یکپارچه‌سازی](integration.fa.md)، [پروتکل‌ها](protocols.fa.md)، [مسیریابی](routing.fa.md)، [لینک‌های محافظت‌شده](crypto.fa.md)، [نشانی پشتیبان](fallback.fa.md) و [عیب‌یابی](diagnostics.fa.md) را بخوانید.

## معنی عدد پینگ

| روش | معنی نتیجه |
| --- | --- |
| TCP | زمان واقعی برقراری اتصال، بدون تقسیم بر 3.3. بازبودن پورت، احراز هویت VPN یا دسترسی اینترنت را ثابت نمی‌کند. |
| DoDo Ping | یک برآورد: زمان HTTP GET از پروفایل پشتیبانی‌شده، تقسیم بر 3.3. این عدد زمان خام HTTP نیست. |
| HTTP GET / HEAD | زمان واقعی درخواست از پروفایل، بدون تقسیم. آزمون سرعت نیست. |
| ICMP | زمان پاسخ اکو؛ ارائه‌دهنده ممکن است ICMP را مسدود کند درحالی‌که VPN کار می‌کند. |

Hysteria از UDP استفاده می‌کند و TCP معمولی برای آزمایش آن مناسب نیست؛ در صورت پشتیبانی، بررسی HTTP از پروفایل انجام می‌شود. در حالت TCP اندروید، balancerها و JSONهای پیچیده یا مبهم نیز از پروفایل کامل بررسی می‌شوند، نه از یک خروجی تصادفی. تعداد آزمایش‌ها محدود است و VPN فعال قطع و وصل نمی‌شود.

## محدودیت پروتکل و سیستم‌عامل

- AmneziaWG در Android حفظ شده و **در iOS پشتیبانی نمی‌شود**. به WireGuard معمولی تبدیل نمی‌شود و نباید آن را در نسخهٔ بومی جدید Mac موجود فرض کرد.
- WireGuard معمولی فقط در قالب‌های URI/پروفایل مستند پشتیبانی می‌شود؛ هر چیدمان peer یا افزونهٔ Amnezia را شامل نمی‌شود.
- پشتیبانی JSON کامل به‌معنای اجرای هر پیکربندی سرور Xray روی تلفن نیست. ورودی‌های محلی و تنظیمات اجرا ممکن است سازگار شوند؛ پروتکل، انتقال، نسخهٔ هسته و دسته‌های داده مهم‌اند.
- Live Activity / Dynamic Island در iPhone به iOS 16.1+، دستگاه سازگار، مجوز و تنظیم فعال DoDo نیاز دارد. پشتیبانی iOS 15 شامل این امکانات سیستم نیست.
- اسکن QR به مجوز دوربین نیاز دارد. ورود دستی و کلیپ‌بورد، به‌ویژه برای لینک رمز‌شدهٔ طولانی، جایگزین‌های مفیدی‌اند.
- Happ crypto/دیپ‌لینک، Lite Mode، Premium API عمومی، تغییر اجباری ظاهر از سوی ارائه‌دهنده و No Limit Mode در این یکپارچه‌سازی پشتیبانی نمی‌شوند.

## امکانات ارائه‌دهندگان: وضعیت و مرزها

| قابلیت | وضعیت |
| --- | --- |
| ارائهٔ معمول کلید | به حساب DoDo، توکن محرمانهٔ API پنل یا ماژول نیاز ندارد. HTTPS و پاسخ پشتیبانی‌شده کافی است. |
| ثبت‌نام Google و DNS TXT میزبان دقیق | دسترسی زودهنگام رایگان. تأیید DoDo جدا از کنترل DNS است. |
| پنل روی سرور ارائه‌دهنده | دسترسی زودهنگام؛ کارخواه محدود API DoDo است، نه نسخهٔ ادمین مرکزی یا دسترسی به دادهٔ دیگران. |
| برند عمومی و استوری | یکپارچه‌سازی زودهنگام: ارائه‌دهندهٔ تأییدشده، تأیید DNS معتبر برای host دقیق، هدر `x-dodo-provider-id` در پاسخ موفق و کارخواه جدید سازگار iOS لازم‌اند. شمارهٔ نسخهٔ منتشرشده، وجود همهٔ تغییرات را ثابت نمی‌کند. |
| آمار بر اساس نام/پشتیبانی عمومی | برای iOS و Android مستند شده؛ برآورد نصب و استفاده است، نه شمارش آنلاین یا تعداد دقیق مشترکان. |
| گزارش دستگاه بر اساس provider ID | از گروه‌بندی نام/پشتیبانی جداست. یکپارچه‌سازی iOS در حال بررسی است؛ این آمار در Android **هنوز منتقل نشده**. گزارش کامل چندپلتفرمی را فعلاً وعده ندهید. |
| اثبات حق یک مشترک مشخص | پایلوت امضاشدهٔ اختیاری و جداگانه. ID عمومی و DNS TXT، پرداخت یا فعال‌بودن حساب کاربر را ثابت نمی‌کنند. |
| اعلان push فقط برای مشترکان خود | هنوز عمومی نیست. اتصال محتوای عمومی، مخاطب خصوصی برای اعلان ایجاد نمی‌کند. |
| انتخاب خودکار از API ارائه‌دهنده | در توسعه. توکن مدیریتی API پنل را داخل کلید کاربر نگذارید. |

دکمهٔ انتخاب خودکار DoDo موقتاً در iOS پنهان است. balancer داخل JSON کامل به آن وابسته نیست. تفاوت محتوای عمومی و مجوز مشترک در [مستندات پنل](provider-console.fa.md) آمده است.

## پیش از عرضه به کاربران

1. پلتفرم و شمارهٔ ساخت نصب‌شده را مشخص کنید، نه فقط نام DoDo.
2. ورود، به‌روزرسانی و اتصال واقعی را با پروفایل، DNS و انتقال خود آزمایش کنید.
3. پس از دریافت نشانی پشتیبان در پاسخ موفق، آن را آزمایش کنید.
4. برای لینک محافظت‌شده، مسیر ورود دستی/کلیپ‌بورد و برای کارخواه قدیمی، روش سازگار نگه دارید.
5. پیش از عمومی دانستن یک قابلیت زودهنگام، [تاریخچهٔ انتشار و بازخورد](updates-feedback.fa.md) را بررسی کنید.

خطای ورود نباید بی‌صدا به افزودن موفق بخشی از فهرست تبدیل شود. هنگام به‌روزرسانی ناموفق، سرورهای قبلی باقی می‌مانند. این رفتار از داده محافظت می‌کند، اما سرویس دور از دسترس، رمز اشتباه یا مسیر خراب سمت ارائه‌دهنده را تعمیر نمی‌کند.
