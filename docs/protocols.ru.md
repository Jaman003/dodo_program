# Протоколы, транспорты и TLS

Одного названия протокола недостаточно: протокол, транспорт, параметры защиты и встроенное ядро должны поддерживать то же сочетание, что настроено на сервере. Таблица описывает возможности iOS 2.2.0; особенности Android указаны ниже.

## Протоколы подключения

| Протокол | Формат импорта | Поддержка и ограничения |
| --- | --- | --- |
| VLESS | `vless://`, Xray JSON | Поддерживается, включая совместимые TLS / REALITY-профили |
| VMess | `vmess://` с Base64 JSON, Xray JSON | Поддерживается; транспорт и параметры защиты проверяются |
| Trojan | `trojan://`, Xray JSON | Поддерживается; при импорте URI по умолчанию используется TLS |
| Shadowsocks | `ss://`, Xray JSON | Распространённые варианты SIP002 / Base64. Шифры зависят от ядра; внешние плагины в URI не поддерживаются |
| Hysteria2 | `hy2://`, `hysteria2://`, совместимый Xray JSON | Версия 2; Salamander и параметры hopping в поддерживаемом формате |
| SOCKS5 | `socks://`, `socks5://`, Xray JSON | С именем/паролем или без них. Сам по себе SOCKS не шифрует транспорт |
| Обычный WireGuard | `wg://`, `wireguard://` | С ограничениями: параметры URI или Base64-профиль wg-quick внутри URI. Не произвольные multi-peer файлы и не расширения AmneziaWG |
| AmneziaWG, TUIC, SSR, Hysteria v1 | Собственные схемы | Не поддерживаются в iOS; AmneziaWG не преобразуется в обычный WireGuard |

В совместимом полном JSON могут присутствовать вспомогательные выходы HTTP, SOCKS и WireGuard. Это не означает, что любой соответствующий URI можно импортировать отдельно.

**Android APK:** AmneziaWG сохранён в Android, в отличие от iOS. Для Hysteria2 реализованы импорт и запуск; проверяйте конкретные параметры сервера. Полный JSON требует распознаваемого основного прокси-протокола и его выходов-зависимостей. Перед выдачей одного профиля всем устройствам сверьтесь с [таблицей платформ](compatibility.ru.md).

## Транспорты и поля URI

| Поле | Значения / назначение |
| --- | --- |
| `type` / `network` | `tcp`, `raw`, `ws`, `websocket`, `grpc`, `xhttp`, `splithttp`, `httpupgrade`, `kcp`, `mkcp` |
| Алиасы | `websocket` → WS; `splithttp` → XHTTP |
| `security` | `none`, `tls`, `reality` — только в совместимом с протоколом и ядром сочетании |
| TLS / REALITY | `sni` / `peer`, `fp` / `fingerprint`, `alpn`; для REALITY также `pbk`, `sid`, `spx` |
| WS | `host`, `path` |
| gRPC | `serviceName`, `authority` |
| XHTTP | `host`, `path`, `mode`, JSON-объект `extra` |
| Проверка сертификата | `pcs` / `pinnedPeerCertSha256`, `vcn` / `verifyPeerCertByName` |

Указывайте значения, действительно настроенные на сервере. Для вложенных настроек транспорта, каскадов, балансировщиков и DNS провайдера предпочтителен [полный Xray JSON](integration.ru.md), а не сокращённая ссылка.

**Hysteria2 использует QUIC без `type=quic`.** Передавайте его через `hy2://` или `hysteria2://`. Значения URI-транспорта `quic`, `h2` и `http` не поддерживаются описанным iOS-импортёром. Это ограничение импорта, а не утверждение, что в ядре нет протоколов на QUIC.

## Безопасность и дополнительные параметры

- Неверный pin сертификата, неподдерживаемое обязательное требование ECH и запрос обхода проверки сертификата приводят к отказу импорта такого URI, а не к ослаблению TLS.
- Совместимый полный JSON может содержать TLS-фрагментацию, включая `freedom.settings.fragment`. Отдельного редактора фрагментации нет.
- В подготовленной **iOS 2.2.2 (113)** добавлены совместимые `fm`, `fragment`, `fragmentPackets` / `fragmentLength` / `fragmentInterval` и описанные в документации HTTP-заголовки `fragmentation-*`. Готовый полный JSON имеет приоритет; две маски не складываются, TLS не ослабляется, автоматическая TCP-фрагментация не применяется к Hysteria. Сборка загружена для обработки в App Store Connect, но ещё не отправлена в App Review. [Подробности и статус](ios-2.2.2.ru.md).
- Параметры `flow`, mux, сокетов и транспорта должны соответствовать серверу и ядру. Поддержка VLESS не гарантирует работу любого сочетания Vision / REALITY / XHTTP.
- Успешный импорт не доказывает доступность сервера. [HTTP-проверки и диагностические логи](diagnostics.ru.md) помогают отличить загрузку, авторизацию и сетевой сбой.

DoDo — клиент, а не продавец VPN-доступа. Ключи и параметры серверов выдаёт ваш сервис или администратор.

Источники: [протоколы DoDo](https://dodoproxy.app/docs/#protocols), [транспорты и TLS](https://dodoproxy.app/docs/#transports). Значение настроек ядра — в [официальной документации Xray](https://xtls.github.io/ru/config/).
