## اتصال سرویس

ثبت‌نام رایگان و در مرحله دسترسی زودهنگام است؛ عرضه کامل هنوز در حال آماده‌سازی است. در [DoDo Partners](https://api.dodoproxy.app/) با Google وارد شوید، سرویس خود را بسازید و راه تماس عمومی پشتیبانی را اضافه کنید. رمز پنل Remnawave، توکن مدیریتی و دسترسی به نودهای VPN لازم نیست.

برای برند عمومی و استوری‌ها سه بررسی مستقل لازم است:

1. ورود مالک با Google.
2. تأیید نام میزبان دقیقِ صادرکننده پیکربندی با DNS TXT.
3. تأیید سرویس توسط DoDo.

برای `sub.example.com`، ساختار رکورد چنین است. مقدار واقعی و یکتای پنل خود را به‌جای نمونه بگذارید:

```text
_dodo-verify.sub.example.com
dodo-verification=v1:CODE_FROM_YOUR_ACCOUNT
```

تأیید فقط برای همین میزبان است، نه همه زیردامنه‌ها یا سرویس‌های دیگر یک CDN مشترک. اعتبار آن ۳۰ روز است. هفت روز پیش از پایان هشدار می‌بینید؛ رکورد TXT جدید بگیرید و تمدید را دستی تکمیل کنید. تمدید خودکار در پس‌زمینه وجود ندارد.

## ارسال شناسه ارائه‌دهنده

این هدر واقعی HTTP را به پاسخ موفق HTTPS پیکربندی از میزبان تأییدشده اضافه کنید:

```http
x-dodo-provider-id: YOUR_PROVIDER_UUID_FROM_DODO
```

هدر را در فیلد JSON یا توضیح بدنه قرار ندهید. صفحه خطا، تغییر مسیر یا پاسخ میزبان دیگر برای این اتصال معتبر نیست.

این UUID عمومی است؛ توکن API، وضعیت ویژه، اثبات پرداخت یا اثبات مالکیت کلید یک کاربر نیست. با `providerid` کوتاهِ [آدرس جایگزین](fallback.fa.md) تفاوت دارد. برند عمومی و استوری به ماژول، signer یا کلید خصوصی امضا نیاز ندارند. محتوای بسته مشترکان به بررسی جداگانه حق دسترسی نیاز دارد.

## نصب پنل روی سرور خودتان

[دریافت Provider Console 0.1.1](https://dodoproxy.app/providers/DoDo-Provider-Console-0.1.1.tar.gz) · [راهنمای نصب](https://dodoproxy.app/providers/DoDo-Provider-Console-0.1.1-README-RU.md)

بسته روی Linux با Docker Compose و پشت HTTPS در نشانی دقیق تنظیم‌شده اجرا می‌شود. `SHA256SUMS` را بررسی و راهنمای داخل بسته را دنبال کنید. دسترسی root به زیرساخت VPN، شبکه میزبان، Docker socket یا ماژول Remnawave لازم نیست.

نصب را با کد خصوصی یک‌بارمصرف و ورود Google تأیید کنید؛ سپس جداگانه با نقش مالک یا ویرایشگر وارد شوید. تأیید نصب جای مجوز شخص را نمی‌گیرد. هر نصب دسترسی قابل‌لغو و محدود به همان ارائه‌دهنده در API مرکزی DoDo دارد. پنل مدیر اصلی، کلیدهای اصلی پلتفرم و اعتبارنامه push در بسته نیستند. داده‌ها و رسانه‌های منتشرشده در سمت DoDo ذخیره می‌شوند.

## استوری و آمار

| قابلیت | محدوده و وضعیت |
| --- | --- |
| استوری | پیش‌نویس، پیش‌نمایش، انتشار برای ۱۲ یا ۲۴ ساعت، لغو انتشار و بایگانی. DNS معتبر، تأیید DoDo و نسخهٔ جدید سازگار iOS لازم است. در دسترسی اولیه، نمایش به کلاینت‌های سازگار محدود است و همهٔ نسخه‌های نصب‌شده را پوشش نمی‌دهد. |
| رسانه | JPEG، PNG یا WebP تا ۱۰ مگابایت؛ MP4 تا ۱۶ مگابایت و ۳۰ ثانیه. پیش از تعویض رسانه، انتشار استوری را متوقف کنید. |
| آمار با provider ID | سرور و پنل 0.1.1 آماده‌اند: آمار تجمیعی مدل، نسخه سیستم و برنامه، روزهای UTC و فیلترهای ۱/۷/۳۰ روز و پلتفرم. این محدوده هنوز با نسخه جدید نصب‌شده/منتشرشده iOS تأیید نشده و به Android منتقل نشده است. |
| push اختصاصی، استوری بسته و انتخاب خودکار با API | هنوز برای استفاده عمومی آماده نیستند. متعادل‌کننده‌های داخل Xray JSON قابلیت جداگانه‌ای هستند. |
| نقشه شبکه | آزمایش بسته. Remnawave دستی و با دسترسی فقط‌خواندنی متصل می‌شود؛ پنل اختصاصی به اتصال‌دهندهٔ جدا نیاز دارد. از دادهٔ تجمیعی استفاده می‌شود، نه `geoip.dat` / `geosite.dat`؛ IP خام و موقعیت دقیق نمایش داده نمی‌شود. شناسهٔ ارائه‌دهنده به‌تنهایی آن را فعال نمی‌کند. |

استوری‌ها عمومی هستند؛ لینک محرمانه، اطلاعات مشتری یا محتوای مخصوص مشترکان پولی در آن‌ها قرار ندهید.

آمار فعلیِ گروه‌بندی‌شده با `profile-title` و `support-url` برای مالک DoDo است. یکسان بودن نام یا راه تماس، حق دسترسی ارائه‌دهنده به آن داده‌ها را ایجاد نمی‌کند. گزارش‌های provider-ID به میزبان دقیقِ تأییدشده و مجوز سرویس نیاز دارند.

شمارش مربوط به نصب‌هایی است که گزارش فرستاده‌اند، نه افراد آنلاین یا مشترکان پولی. یک نصب ممکن است چند ارائه‌دهنده داشته باشد. پنل فقط آمار تجمیعی می‌گیرد، نه کلید، URL، HWID یا فهرست دستگاه‌های منفرد. ارسال حداکثر دو بار در ۲۴ ساعت و با فاصله حداقل ۱۲ ساعت است.

قطع پنل یا API نباید واردکردن پیکربندی یا ترافیک VPN را متوقف کند. پس از پایان مهلت یک تغییر، پیش از تکرار بخش را تازه‌سازی و نتیجه را بررسی کنید. دسترسی زودهنگام به معنی تکمیل آزمایش با ارائه‌دهنده واقعی یا ظرفیت نامحدود نیست.
