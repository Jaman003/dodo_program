## 延迟测试测量什么？

以下模式对应 iOS 2.2.0 和 Android APK 2.2.0 (2107) 文档，不表示所有平台的行为完全相同。

| 模式 | 测量内容 | 局限 |
| --- | --- | --- |
| TCP（默认） | 建立到服务器的 TCP 连接所需时间，不做除法。 | 端口开放不能证明认证、互联网访问或 VPN 速度正常。 |
| DoDo Ping | 通过受支持配置发送 HTTP GET，显示值除以 3.3。 | 是估算值，不是原始实测延迟。 |
| HTTP GET / HEAD | 通过配置向 HTTPS 测试 URL 发送对应请求，不做除法。 | 测量请求时间，不是带宽。 |
| ICMP | 主机 ICMP 响应时间。 | 服务器可能禁用 ICMP，但 VPN 仍正常工作。 |

Hysteria 使用 UDP，因此 TCP 模式会通过配置执行 HTTP 检查。负载均衡及复杂或不明确的配置也需要完整配置检查，不能用单端口结果代表整条链路。Android 完整配置检查中，核心启动和本地认证会消耗总超时，但不计入显示的 HTTP 请求时间。

iOS 路径为 **设置 → 高级用户 → 延迟测试**。可以设置 HTTPS 测试 URL 和 1–10 秒超时。并发检查数量有限，不会重新连接当前 VPN。JSON 负载均衡按完整配置和自身选择规则测试。

原始测量单独保存。切换方法会启动适合的新检查，不会把旧方法的数值当作新结果。更新配置时，匹配服务器保留最近值。`N/A` 表示检查失败或该配置不支持；`…` 表示当前方法尚无结果。

测试成功不等于完整 VPN、TUN、DNS、路由或速度测试通过。如果延迟正常但网站无法访问，请提供协议、错误代码和复现步骤，不要关闭 TLS 验证。

## 本地日志与自动报告

iOS 的 **设置 → 高级用户 → 日志** 集中提供启用、实时查看、暂停、复制和清除功能。分享前请检查内容，日志中可能仍含服务器技术地址。

自动技术报告与本地日志不同。只有用户同意后才开始发送；可在应用中关闭发送、撤回同意并删除已发送数据。

报告仅包含有界的技术信息，例如错误代码、阶段、设备型号、系统和应用版本。不包含秘密配置 URL、订阅 HWID、完整配置或流量内容。报告发送给 DoDo 开发者，不进入服务商控制台。

| 平台 | 范围 | 限制 |
| --- | --- | --- |
| iOS | 已处理的导入/VPN 错误、有限队列、发送与删除控制；Apple MetricKit 的有限 crash/hang 标记。 | 不是完整崩溃文件或调用栈。不能涵盖所有扩展崩溃、内存终止和卡顿。Apple 数据可能延迟至下次启动后到达。 |
| Android APK | 经同意的报告、受保护队列、应用运行时发送；加载详情区分网络、响应和导入失败。 | 应用关闭后没有永久发送器，不保证收集所有系统崩溃和卡顿。 |

通知权限不能代替诊断同意。加载配置时交给服务商的 HWID 和设备头属于另一条数据流。服务商只能收到用户另外决定分享的本地日志。

## 使用统计是另一项功能

DoDo 所有者统计按适合的公开 `profile-title` 和清理后的 `support-url` 分组，结合型号、平台及应用/系统版本。名称只是分组标签，不是所有权证明。macOS 和 Windows 尚未接入此统计。

iOS 2.2.0 和 Android APK 2.2.0 在隐私政策页面提供控制；此前的拒绝会保留。这与技术错误报告同意是两个独立设置。

最多 **24 小时尝试两次，间隔至少 12 小时**。统计服务器不可用不应阻止启动、导入或 VPN。计数是发送报告的安装和配置数量，不是在线人数。

详细记录最多保留 30 天。月度历史从 2026 年 11 月 9 日开始；已关闭的匿名汇总不自动到期，小规模分组会隐藏。不会补造此前历史。撤回后删除个体记录并重算当前月，但无法从已关闭的匿名汇总中分离某个人。

服务商仪表盘使用独立、经过验证的 provider-ID 范围。名称或联系方式相同不会开放所有者旧报告。后端与控制台已准备，但此范围的新 iOS 发布尚未验证，Android 还未移植。参见[控制台状态](provider-console.zh-CN.md)。
